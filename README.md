## 📌 Sobre o Projeto

O **Criança Feliz** é um projeto social criado para arrecadação, divulgação de um ação social do Dia das Crianças.

A plataforma foi desenvolvida com foco em **experiência do usuário (UX)**, **acessibilidade** e **design responsivo**, garantindo navegação fluida em qualquer dispositivo móvel ou desktop.

### ✨ Principais Funcionalidades
- 🏆 **Seção Hero Interativa:** Apresentação clara da causa com chamada para doação.
- 🖼️ **Galeria de Projetos por Ano:** Navegação interativa em abas (*pills*) para visualizar fotos de edições anteriores (2018, 2019, 2024, 2025 e 2026).
- 💬 **Botão Flutuante de WhatsApp:** Canal direto para dúvidas, parcerias e doações rápidas.
- 📱 **Layout Mobile-First:** Otimizado para carregamento instantâneo em conexões móveis.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web modernas para garantir performance, código limpo e fácil manutenção:

- **HTML5:** Estruturação semântica para melhor acessibilidade e SEO.
- **CSS3 / Bootstrap 5:** Estilização responsiva, componentes visuais (*badges*, *pills*, *cards*) e grid flexível.
- **JavaScript (ES6):** Manipulação dinâmica de componentes, controle das abas de navegação e eventos de interface.
- **Bootstrap Icons:** Iconografia leve e vetorial.
